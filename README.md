# CalCal

Fitness recording and diet calculator, hosted on GitHub Pages.

- `index.html`: page layout
- `css/styles.css`: styles
- `js/app.js`: application logic
- `js/firebase.js`: Firebase connection
- `js/nutrition.js`: portion calculations and missing nutrition values

Food categories, foods, and goals are stored in Firestore under `CalCal`.
Daily food, water, and supplement records are stored under `days`.
